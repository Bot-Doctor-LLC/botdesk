# Contributing

Read `AGENTS.md`, `ROADMAP.md`, and `docs/DESIGN-CHECKLIST.md` before starting. Work on one issue per branch and pull request, preserve the MonoCode interface, add focused tests, and record exact verification commands. Never add credentials, client data, live environment identifiers, or local machine paths.

Run the checks documented in `README.md` before opening a pull request. User-visible changes require equivalent before/after screenshots made with synthetic data.
